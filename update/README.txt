GameNet Plus Manager - Update Folder

برای آپدیت برنامه، فایل ZIP یا پوشهٔ نسخهٔ جدید را همین‌جا قرار بده و نام فایل را به من بگو.

لطفاً این فایل‌ها را داخل نسخهٔ جدید جایگزین نکن:

- .env
- .mysql_config.json
- پوشهٔ node_modules
- پوشهٔ dist

قبل از آپدیت از دیتابیس game_net_club در phpMyAdmin گزینهٔ Export بگیر.

بعد از قرار دادن فایل جدید فقط پیام بده:

«فایل آپدیت داخل پوشه update قرار گرفت؛ آپدیتش کن.»

سپس فایل بررسی می‌شود، از تنظیمات و دیتابیس محافظت می‌شود، وابستگی‌ها نصب می‌شوند و نسخهٔ جدید build و تست می‌شود.
